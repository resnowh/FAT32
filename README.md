# FAT32 文件系统实现

合肥工业大学《操作系统课程设计》（2022—2023 学年第二学期）。

用 C 从零实现一个可读写磁盘镜像的简易 FAT32 文件系统，不依赖任何现成的文件系统库。

## 实现内容

- 解析 FAT32 引导扇区（BPB），取得每簇扇区数、FAT 表位置、根目录簇号等元信息
- FAT 表读写，簇链的分配与回收
- 目录项解析与创建（短文件名 8.3 格式）
- 文件读取、写入与截断
- 通过文件模拟磁盘，直接操作 `disk_test.img`

## 文件说明

| 文件 | 作用 |
|---|---|
| `xfat.c` / `xfat.h` | FAT32 核心：引导扇区解析、FAT 表、目录项、文件读写 |
| `xdisc.c` | 磁盘镜像的读写封装 |
| `xdisk.h` | 磁盘层对外接口 |
| `driver.c` | 驱动程序入口 |
| `fatfs_test.c` | 测试用例入口 |
| `xtypes.h` | 基础类型定义 |
| `FAT32.vcxproj` | Visual Studio 工程文件 |
| `disk_test.img` | 1 MB 测试镜像 |

## 构建与运行

用 Visual Studio 打开 `FAT32.vcxproj` 编译，运行时把 `disk_test.img` 放在工作目录下即可。

## 说明

仓库中的 `disk_test.img` 是一个 1 MB 的 FAT32 测试镜像，用于验证读写逻辑；原始开发用的 1 GB `disk.img` 体积过大，未纳入版本库。
